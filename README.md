# PersonManagement

در صورتی که عملیات با خطا مواجه شود، ثبت خطاها (Logging)، استفاده از الگوی Retry Pattern برای خطاهای موقتی با Polly، استفاده از Middleware برای Error Handling ،اعتبارسنجی ورودی‌ها (Validation)،  استفاده از Health Checks برای مانیتورینگ سلامت سرویس ها، APM از خانواده ELK برای بررسی سرویس هایی که لود سنگین دارن و خطاهای لود ایجاد میکنند و سرویس هایی که درست Dispose نمی شوند اصلاحا از حافظه آزاد نمیشوند (Concurrent)
